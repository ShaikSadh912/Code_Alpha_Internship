# 🤖 AI FAQ Chatbot

An AI-powered FAQ Chatbot developed using Python and Natural Language Processing (NLP). The chatbot answers frequently asked questions related to Artificial Intelligence, Machine Learning, Python, Data Science, GitHub, and other technology topics through an interactive graphical user interface built with Tkinter.

---

## 📌 Features

- 💬 Interactive GUI using Tkinter
- 🤖 Intelligent FAQ matching using NLP
- 📊 TF-IDF Vectorization for text representation
- 📈 Cosine Similarity for finding the best matching question
- 🧹 Automatic text preprocessing using NLTK stopwords
- ⚡ Fast and lightweight desktop application
- 📚 Includes 40+ technology-related FAQs

---

## 🛠️ Technologies Used

- Python
- Tkinter
- Scikit-learn
- NLTK

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/Sadh91206/Code_Alpha_Internship.git
```

### 2. Navigate to the project folder

```bash
cd Code_Alpha_Internship/FAQ_Chatbot
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the chatbot

```bash
python chatbot.py
```
